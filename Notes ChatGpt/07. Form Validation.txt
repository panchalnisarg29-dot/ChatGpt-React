✅ What is Form Validation?

Form validation means:
👉 Check user input before submitting the form

We make sure:

Required fields are filled ✅
Email format is correct 📧
Password length is enough 🔐
Wrong data is stopped ❌

----------------------------------------------------------

🧠 Real-Life Example

Imagine a school form 🏫
If you leave your name empty, teacher says:

“Please fill your name”

That is validation 😄

------------------------------------------------------------

🔹 Types of Form Validation
1️⃣ Client-Side Validation (React)

Happens in browser
Fast
User-friendly

2️⃣ Server-Side Validation

Happens on backend
More secure

👉 Today we focus on React (client-side).

------------------------------------------------------------------

🔥 Email Validation Example
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

if (!emailRegex.test(email)) {
  setError("Enter a valid email");
}

👉 This checks email format.
-----------------------------------------------------------------------


🔥 Password Validation Example
if (password.length < 6) {
  setError("Password must be at least 6 characters");
}

----------------------------------------------------------------------------------

🔁 Live Validation (onChange)
<input
  value={email}
  onChange={(e) => {
    setEmail(e.target.value);
    if (!e.target.value.includes("@")) {
      setError("Invalid email");
    } else {
      setError("");
    }
  }}
/>

👉 Error shows while typing ✨

------------------------------------------------------------------------------------

🧠 Common Validation Rules
_______________________________________
| Rule         | Example              |
| ------------ | -------------------- |
| Required     | name !== ""          |
| Min length   | password.length ≥ 6  |
| Email format | regex                |
| Match fields | password === confirm |
