✅ What is a List in React?

A list means:
👉 Showing multiple items on the screen using data.

Examples:

List of names
List of products
Todo list
Menu items

In React, we usually use arrays to create lists.


🔥 Rendering a List in React

function FruitList() {
  const fruits = ["Apple", "Banana", "Mango"];

  return (
    <ul>
      {fruits.map((fruit) => (
        <li>{fruit}</li>
      ))}
    </ul>
  );
}


What’s happening?

map() loops through array
Each item becomes JSX (<li>)
React displays the list 🎉

=============================================================
❗ Warning You Will See

React will show this warning:
“Each child in a list should have a unique key”

That’s why keys exist 😄

===============================================================

✅ What is a Key?
A key is a unique ID for each list item.

👉 It helps React:

Identify items
Update only changed items
Improve performance 🚀


🔥 Correct List with Keys
function FruitList() {
  const fruits = ["Apple", "Banana", "Mango"];

  return (
    <ul>
      {fruits.map((fruit, index) => (
        <li key={index}>{fruit}</li>
      ))}
    </ul>
  );
}


🧠 What does key do? (Simple)

Think of students in a class 👨‍🎓👩‍🎓
Each student has a roll number.

👉 React uses key like a roll number.

🔥 Better Example: List of Objects (Best Practice ✅)
function UserList() {
  const users = [
    { id: 1, name: "Ali" },
    { id: 2, name: "Sara" },
    { id: 3, name: "John" },
  ];

  return (
    <ul>
      {users.map((user) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}

Best Practice:

✔ Use unique id
❌ Avoid index if possible

---------------------------------
❓ Why NOT use index as key?

Index changes when:

Item is added
Item is removed
Item is reordered

👉 This can cause bugs 😬

Use index only for:

Static lists
No add/remove
-----------------------------------

🧠 Easy Summary (Remember This!)

List = show array data on UI
map() = loop through array
Key = unique identity
Key helps React update fast ⚡
