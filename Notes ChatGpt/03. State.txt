✅ What is State?

State is data inside a component.

👉 State can change
👉 When state changes, the UI updates automatically

Simple Example of State 👇
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        Increase
      </button>
    </>
  );
}

What is happening?

count = current state value
setCount = function to update state
Clicking button increases the number 🎉

----------------------------------------------------------

Props vs State (Very Easy Table) 🧩
_____________________________________
| Props                         | State                            |
|____________________________________|
| Passed from parent     | Inside the component |
| Read-only                  | Can be changed          |
| Used to display data  |Used to manage data    |

✅ Explain this line step by step

<button onClick={() => setCount(count + 1)}>

1️. onClick
This is a React event
It runs when the button is clicked


👉 Same idea as clicking a button in real life 🖱️

2️. () => { } (Arrow Function)

Code:
() => setCount(count + 1)

This is a function
React runs this function only when you click the button

❌ If we don’t use a function, it will run automatically (wrong!)

3️. setCount
This is the state update function
It changes the value of count

4️. count + 1
Takes the current value
Adds 1 to it

🔁 Full Meaning in Simple Words 🧠
👉 When button is clicked → increase count by 1 → update screen
