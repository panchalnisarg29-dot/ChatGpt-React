A component is a small piece of a website.
You can think of it like a building block.

Each component does one job and you can reuse it many times.

Examples of components:

Button
Header
Footer
Login form
Profile card

Simple Example
Here is a very basic React component:

function Button() {
  return <button>Click Me</button>;
}
export default Button;

------------------------------------------------------
What is happening here?

Button is the component name
It returns HTML (JSX)
This component shows a button

-----------------------------------------------------
Using the Component
You can use this component like this:

<Button />

----------------------------------------------------
Easy Way to Remember 🧠

Component = reusable UI part
Small + reusable
Looks like a function

-------------------------------------------------------
1️.  Function Components (Most Used ✅)

These are simple JavaScript functions.

Example:
function Welcome() {
  return <h1>Hello React</h1>;
}

Key Points:

Written like a function
Easy to understand 😊
Most popular in modern React
Can use Hooks (like useState)
