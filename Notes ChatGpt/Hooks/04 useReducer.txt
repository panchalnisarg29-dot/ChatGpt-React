🧠 First: Why do we need useReducer?

You already know useState.
But when:

State logic becomes complex
Many state values depend on each other
Many actions change state

👉 useState becomes messy 😵

That’s where useReducer helps ✅

-------------------------------------------------------------------

✅ What is useReducer?

useReducer is a React Hook.
It manages state using a reducer function (like a decision maker)

Think of it like:

useState → simple switch
useReducer → control panel 🎛️

------------------------------------------------

🧠 Real-Life Example

Imagine a bank account 🏦
Actions:

Deposit money
Withdraw money
Reset account

👉 One place decides how balance changes → reducer

----------------------------------------------------------------

🔹 Basic Syntax of useReducer
const [state, dispatch] = useReducer(reducer, initialState);

Meaning:

state → current value
dispatch → sends action
reducer → function that decides state update
initialState → starting state

--------------------------------------------------------------------

🔹 What is a Reducer Function?
function reducer(state, action) {
  switch (action.type) {
    case "ACTION_NAME":
      return newState;
    default:
      return state;
  }
}


👉 Reducer:

Takes current state
Takes action
Returns new state

🔥 SIMPLE Example: Counter using useReducer
Step 1️⃣ Reducer Function
function reducer(state, action) {
  switch (action.type) {
    case "INCREMENT":
      return state + 1;
    case "DECREMENT":
      return state - 1;
    default:
      return state;
  }
}

Step 2️⃣ Component
import { useReducer } from "react";

function Counter() {
  const [count, dispatch] = useReducer(reducer, 0);

  return (
    <>
      <p>Count: {count}</p>

      <button onClick={() => dispatch({ type: "INCREMENT" })}>
        +
      </button>

      <button onClick={() => dispatch({ type: "DECREMENT" })}>
        -
      </button>
    </>
  );
}

🧩 FULL WORKING EXAMPLE
import { useReducer } from "react";

// 1️⃣ Reducer function
function counterReducer(state, action) {
  if (action.type === "INCREMENT") {
    return { count: state.count + 1 };
  }

  if (action.type === "DECREMENT") {
    return { count: state.count - 1 };
  }

  if (action.type === "RESET") {
    return { count: 0 };
  }

  return state;
}

function CounterApp() {
  // 2️⃣ useReducer hook
  const [state, dispatch] = useReducer(counterReducer, { count: 0 });

  return (
    <div style={{ padding: "20px" }}>
      <h1>useReducer Counter</h1>
      <p>Count: {state.count}</p>

      <button onClick={() => dispatch({ type: "INCREMENT" })}>
        +
      </button>

      <button onClick={() => dispatch({ type: "DECREMENT" })}>
        -
      </button>

      <button onClick={() => dispatch({ type: "RESET" })}>
        Reset
      </button>
    </div>
  );
}

export default CounterApp;

function expenseReducer(state, action) {
  switch (action.type) {
    case "ADD":
      return [...state, action.payload];

    case "DELETE":
      return state.filter(e => e.id !== action.payload);

    case "EDIT":
      return state.map(e =>
        e.id === action.payload.id ? action.payload : e
      );

    default:
      return state;
  }
}
