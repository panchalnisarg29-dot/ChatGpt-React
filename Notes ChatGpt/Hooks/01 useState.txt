✅ What is useState?

useState is a React Hook.

👉 It lets a function component remember data
👉 It lets the UI change when data changes

In short:

useState = memory + re-render

🧠 Real-Life Example

Think of a counter 

Number starts at 0
Click button → number increases
Screen updates automatically

That “remembering the number” is useState.

🔹 Basic Syntax of useState
const [state, setState] = useState(initialValue);

Meaning:

state → current value
setState → function to update value
initialValue → starting value

🔥 Very Simple Example
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        Increase
      </button>
    </>
  );
}

🧠 Step-by-Step Explanation

1️⃣ Initial State
useState(0)
👉 count = 0

2️⃣ Reading State
<p>{count}</p>
👉 Displays current value

3️⃣ Updating State
setCount(count + 1)
👉 Changes value
👉 React re-renders UI 🎉

❓ Why can’t we do this?
count = count + 1 ❌

Because:

React will NOT re-render
UI will NOT update
👉 Always use setCount() ✅

🔁 useState with Different Data Types
🔹 String
const [name, setName] = useState("");

🔹 Boolean
const [isOpen, setIsOpen] = useState(false);

🔹 Array
const [todos, setTodos] = useState([]);

🔹 Object
const [user, setUser] = useState({ name: "", age: 0 });

🔥 Updating Object State
setUser({ ...user, name: "Ali" });
👉 Keep old values
👉 Update only one field

🔥 Updating Array State
setTodos([...todos, "New Todo"]);
👉 Copy old array
👉 Add new item

🧠 IMPORTANT RULES of useState

❗ Hooks must be:
Used at top level
Not inside loops
Not inside conditions
Only inside React components


function Toggle() {
  const [on, setOn] = useState(false);

  return (
    <button onClick={() => setOn(!on)}>
      {on ? "ON" : "OFF"}
    </button>
  );
}
