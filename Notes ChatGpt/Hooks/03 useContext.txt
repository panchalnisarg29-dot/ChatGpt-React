🧠 The Problem useContext Solves (VERY IMPORTANT)

Imagine this situation 👇

You have data in a Parent component, and you want to send it to a deep child.

❌ Without useContext → you must pass props again and again
This is called props drilling 😫

🔹 Props Drilling Example (Problem)
<App>
  <Parent>
    <Child>
      <GrandChild /> ❌ needs data
    </Child>
  </Parent>
</App>

You pass props like:

App → Parent → Child → GrandChild

Annoying, right? 😅

=========================================================================================

✅ Solution: useContext

👉 useContext lets you share data globally
👉 Any component can access it without props

✅ What is useContext?
useContext is a React Hook.

It allows components to read data from Context

Think of Context as a global storage 📦
=====================================================================================

🧠 Real-Life Example

Imagine a WiFi router 📡

Router = Context
Devices = Components
Any device can connect without cables (props)

======================================================================================

🔹 Steps to Use useContext (VERY IMPORTANT)
Step 1️⃣ Create Context
import { createContext } from "react";

const UserContext = createContext();

Step 2️⃣ Provide Context Value
<UserContext.Provider value="John">
  <App />
</UserContext.Provider>

Step 3️⃣ Consume Context (useContext)
import { useContext } from "react";

const name = useContext(UserContext);
-----------------------------------------------
🔥 FULL SIMPLE EXAMPLE (Read Carefully)
🟢 App.js
import { createContext } from "react";
import Home from "./Home";

export const UserContext = createContext();

function App() {
  return (
    <UserContext.Provider value="John">
      <Home />
    </UserContext.Provider>
  );
}

export default App;

🟢 Home.js
import Profile from "./Profile";

function Home() {
  return <Profile />;
}

export default Home;

🟢 Profile.js
import { useContext } from "react";
import { UserContext } from "./App";

function Profile() {
  const user = useContext(UserContext);

  return <h1>Hello {user}</h1>;
}

export default Profile;


---------------------------------------------------

🧠 What Just Happened?

App provides data
Profile consumes data
No props passed ❌
Clean code 😄

-----------------------------------------

❗ When to Use useContext

✅ Theme (dark/light)
✅ User login info
✅ Language
✅ Global settings

❌ NOT for everything (can slow app)

🧠 Easy Comparison
| Props           | Context         |
| --------------- | --------------- |
| Passed manually | Global access   |
| For small apps  | For shared data |
| Props drilling  | No drilling     |


🎯 Simple Rule to Remember

If many components need same data → useContext


🎉 Final Summary

useContext shares data globally
Avoids props drilling
Uses Provider + Consumer
Clean & powerful

## ✅ FULL WORKING THEME CONTEXT EXAMPLE

### 📁 File: `ThemeContext.js`

```jsx
import { createContext } from "react";

const ThemeContext = createContext();

export default ThemeContext;
```

---

### 📁 File: `App.jsx`

```jsx
import { useState } from "react";
import ThemeContext from "./ThemeContext";
import Navbar from "./Navbar";

function App() {
  const [theme, setTheme] = useState("light");

  return (
    <ThemeContext.Provider value={{ theme, setTheme }}>
      <div
        style={{
          height: "100vh",
          backgroundColor: theme === "light" ? "#ffffff" : "#222222",
          color: theme === "light" ? "#000000" : "#ffffff",
          padding: "20px",
        }}
      >
        <h1>Theme Context Example</h1>
        <Navbar />
        <p>Current Theme: {theme}</p>
      </div>
    </ThemeContext.Provider>
  );
}

export default App;
```

---

### 📁 File: `Navbar.jsx`

```jsx
import { useContext } from "react";
import ThemeContext from "./ThemeContext";

function Navbar() {
  const { theme, setTheme } = useContext(ThemeContext);

  function toggleTheme() {
    setTheme(theme === "light" ? "dark" : "light");
  }

  return (
    <button onClick={toggleTheme}>
      Change Theme
    </button>
  );
}

export default Navbar;
```

## 🧠 NOW LET’S UNDERSTAND IT STEP BY STEP

---

## 🔹 1. What is `ThemeContext`?

```js
const ThemeContext = createContext();
```

Think of `ThemeContext` as a **global box** 📦
that can store data and share it with any component.

---

## 🔹 2. What does `ThemeContext.Provider` do?

```jsx
<ThemeContext.Provider value={{ theme, setTheme }}>
```

This means:

> “I am providing `theme` and `setTheme` to all child components.”

So any component **inside** this Provider can access:

* `theme`
* `setTheme`

---

## 🔹 3. Why do we use `value={{ theme, setTheme }}`?

Because we want **both**:

* current theme value
* function to change theme

This allows child components to:

* READ state
* UPDATE state

---

## 🔹 4. How does `Navbar` get the data?

```js
const { theme, setTheme } = useContext(ThemeContext);
```

This line means:

> “Give me whatever data the nearest ThemeContext Provider is providing.”

No props
No drilling
Direct access 🚀

---

## 🔹 5. What happens when button is clicked?

```js
setTheme(theme === "light" ? "dark" : "light");
```

### Flow:

1. Button clicked
2. `setTheme` updates state in `App`
3. `App` re-renders
4. Context value changes
5. All components using ThemeContext re-render
6. UI updates automatically

---

## 🔁 VISUAL FLOW (IMPORTANT)

```
Navbar (button click)
   ↓
setTheme()
   ↓
App state changes
   ↓
ThemeContext value changes
   ↓
All consumers update
```

---

## 🧠 WHY useContext is powerful

Without context ❌:

```jsx
<App theme={theme} setTheme={setTheme}>
  <Navbar theme={theme} setTheme={setTheme} />
</App>
```

With context ✅:

```jsx
<ThemeContext.Provider value={{ theme, setTheme }}>
  <Navbar />
</ThemeContext.Provider>
```

No prop drilling 🎯

> **`useContext` lets any component read and update shared state without passing props manually.**
