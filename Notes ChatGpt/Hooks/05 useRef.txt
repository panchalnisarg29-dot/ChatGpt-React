✅ What is useRef?
useRef is a React Hook.
👉 It lets you store a value that does NOT cause re-render
👉 It also lets you directly access a DOM element

🧠 Think of useRef like this
useState → memory with re-render
useRef → memory without re-render

👉 useRef is like a sticky note 📝
React doesn’t re-render when it changes.

-----------------------------------------------------------------------
🔹 Basic Syntax
const myRef = useRef(initialValue);

myRef.current → stores the value

------------------------------------------------------------------------

🔥 Use Case 1: Access DOM Element (MOST COMMON)
Example: Focus Input Automatically
import { useRef, useEffect } from "react";

function InputFocus() {
  const inputRef = useRef(null);

  useEffect(() => {
    inputRef.current.focus();
  }, []);

  return <input ref={inputRef} />;
}

Explanation 🧠👇

ref={inputRef} → connects ref to input
inputRef.current → actual input element
.focus() → focuses input

------------------------------------------------------------------

🔥 Use Case 2: Store Value Without Re-render
import { useRef, useState } from "react";

function Counter() {
  const countRef = useRef(0);
  const [count, setCount] = useState(0);

  function increase() {
    countRef.current += 1;
    setCount(count + 1);
    console.log("Ref:", countRef.current);
  }

  return <button onClick={increase}>{count}</button>;
}

👉 countRef changes but UI doesn’t care
👉 useState updates UI

-----------------------------------------------------------------------

🔥 Use Case 3: Previous Value
import { useRef, useEffect, useState } from "react";

function Example() {
  const [value, setValue] = useState(0);
  const prevValue = useRef(null);

  useEffect(() => {
    prevValue.current = value;
  }, [value]);

  return (
    <p>
      Current: {value} | Previous: {prevValue.current}
    </p>
  );
}

👉 Useful for comparisons

----------------------------------------------------------------------
❌ What useRef is NOT for
❌ Do NOT use it to update UI
❌ Do NOT replace useState


🧠 useRef vs useState
| useState         | useRef          |
| ---------------- | --------------- |
| Causes re-render | No re-render    |
| UI updates       | Background data |
| For visible data | For hidden data |


🔥 Real-Life Examples

Focus input on page load
Scroll to section
Store timer ID
Track previous value



❗ Important Rules
Value is stored in .current
Changing .current does NOT re-render
Safe across renders

🎯 Mini Project Example
function ClickTracker() {
  const clicks = useRef(0);

  function handleClick() {
    clicks.current += 1;
    console.log("Clicked:", clicks.current);
  }

  return <button onClick={handleClick}>Click</button>;
}


🎉 Final Easy Summary
useRef stores value without re-render
Used to access DOM elements
Good for timers, focus, previous values
.current is the key 🔑
